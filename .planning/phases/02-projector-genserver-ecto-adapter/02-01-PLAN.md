<objective>
Build the Wave 0 Postgres test harness: a per-projection isolated test Ecto.Repo
(`Orkestra.Test.ProjectionRepo`) with its own `migration_source`, an example
read-model schema and an in-code migration that creates its table, the
`elixirc_paths` wiring so `test/support/` compiles, and the `test_helper.exs`
changes that conditionally start the Repo, set `Ecto.Adapters.SQL.Sandbox` to
manual mode, and exclude `:postgres`-tagged tests by default.

This harness proves the per-projection Repo isolation (STORE-04) and isolated
migration history (MIG-01) infrastructure that the adapter and GenServer plans
build their integration tests on. No projector runtime code is written here.

Purpose: Establish the only Postgres test surface in the phase so Plans 02 and
03 can write integration tests against a real DB without re-inventing setup, and
so the existing fast async suite stays green when no Postgres is present.
Output: mix.exs elixirc_paths, three test/support modules, updated test_helper.exs.
</objective>
