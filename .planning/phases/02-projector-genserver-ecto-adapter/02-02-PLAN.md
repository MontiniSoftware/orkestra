<objective>
Implement `Orkestra.Projection.Storage.Postgres` — the PostgreSQL/Ecto storage
adapter (STORE-02) — implementing the Phase 1 `Storage` behaviour. `write/4`
returns `{:ok, Ecto.Multi.t()}`: a pure, composable read-model write fragment
that the Projector GenServer (Plan 03) appends to its checkpoint upsert Multi and
commits in one transaction (the STORE-03 atomic co-write happens in Plan 03; this
plan provides the read-model half of it). `reset/2` clears the projector's
read-model rows on the injected isolated Repo (STORE-04 / rebuild prep).

The adapter is guarded with `Code.ensure_loaded?(Ecto.Multi)` so the library still
compiles without Ecto. Tests run against the real test Repo from Plan 01 under
`Ecto.Adapters.SQL.Sandbox`, tagged `:postgres` so they are skippable.

Purpose: Deliver the Postgres write descriptor in the exact Multi-fragment shape
the GenServer expects, with the `:read_model_`-prefixed step-naming convention
that prevents the documented `Multi.append` name-clash pitfall.
Output: lib/orkestra/projection/storage/postgres.ex + its :postgres-tagged test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| event payload → read-model write | Event data flows into the read-model Multi via the injected handler; crosses into the DB |
| caller (GenServer) → adapter | The Repo is injected at transaction time; the adapter never owns the connection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | event_data persisted via Ecto changeset/`:map` | mitigate | Writes go through Ecto parameterized queries / changesets; `:map` payload is jsonb (no `:erlang.binary_to_term`), consistent with Phase 1 T-01-05 |
| T-02-04 | Tampering | SQL injection via read-model write | mitigate | All writes use Ecto.Multi / Ecto.Query parameter binding — no string-built SQL; `reset/2` uses a parameterized `where` |
| T-02-05 | Repudiation | adapter binding the Repo at call time | accept | Adapter returns a Multi fragment only and never commits; transaction boundary owned by the GenServer (STORE-03) — design-enforced, not a runtime check |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages — ecto/ecto_sql/postgrex approved in Phase 1; no install tasks |
</threat_model>
