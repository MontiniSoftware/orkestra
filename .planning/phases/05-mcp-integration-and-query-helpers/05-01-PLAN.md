1. **naming.ex** -- Add `module_to_table_name/1` function after the existing `module_to_file_path/1`:

```elixir
@doc """
Converts a module name to a pluralised table name.

    iex> OrkestraMcp.Naming.module_to_table_name("MyApp.Orders.OrderReadModel")
    "order_read_models"
"""
def module_to_table_name(module_name) do
  module_name
  |> String.split(".")
  |> List.last()
  |> Macro.underscore()
  |> Kernel.<>("s")
end
```

2. **generator.ex** -- Add five new public functions at the end of the module, before the `# --- Private helpers ---` comment. Follow the exact `{String.trim(source), path}` return contract. The functions are:

**gen_projection/3** `(module_name, repo_module, events)`:
- `events` is a list of event module name strings (already decoded from JSON by the tool).
- Build `project EventModule, fn event, multi -> multi end` clauses using `Enum.map_join("\n\n", ...)`.
- If events is empty, generate a single `project EventModule, fn event, multi -> multi end` clause with a TODO comment.
- The generated module uses `use Orkestra.Projector, repo: #{repo_module}, event_store: Orkestra.EventStore`.
- Return `{String.trim(source), Naming.module_to_file_path(module_name)}`.

**gen_projection_migration/2** `(projector_module_name, timestamp \\ nil)`:
- Compute `ts = timestamp || Calendar.strftime(DateTime.utc_now(), "%Y%m%d%H%M%S")`.
- Compute slug: `projector_module_name |> String.split(".") |> Enum.map(&Macro.underscore/1) |> Enum.join("_")`. This matches the slug derivation in `Orkestra.Projector.__before_compile__/1`.
- Build `file_path = Path.join(["priv", "projections", slug, "migrations", "#{ts}_create_#{slug}_read_model.exs"])`.
- Build a migration module: `defmodule Orkestra.Projection.Migrations.Create#{Macro.camelize(slug)}ReadModel do`, with `use Ecto.Migration`, and `up/down` functions with TODO comments showing example `create table(...)` and `drop table(...)`.
- Return `{String.trim(source), file_path}`.

**gen_read_model/2** `(module_name, fields)`:
- `fields` is a list of maps with keys `"name"` and `"type"` (same shape as gen_event fields).
- Generate an Ecto schema module with `use Ecto.Schema`, `@primary_key {:id, :binary_id, autogenerate: true}`, `@timestamps_opts [type: :utc_datetime_usec]`, and a `schema` block using `Naming.module_to_table_name(module_name)` as the table name.
- Use `format_schema_field/1` private helper (new) to format each field as `    field :name, :type`.
- Return `{String.trim(source), Naming.module_to_file_path(module_name)}`.

**gen_read_model_migration/2** `(schema_module_name, timestamp \\ nil)`:
- Compute `ts` same as gen_projection_migration.
- Compute table_name via `Naming.module_to_table_name(schema_module_name)`.
- Compute slug for the path: `schema_module_name |> String.split(".") |> Enum.map(&Macro.underscore/1) |> Enum.join("_")`.
- Build `file_path = Path.join(["priv", "projections", slug, "migrations", "#{ts}_create_#{table_name}.exs"])`.
- Build a migration module with `use Ecto.Migration`, `create table(:#{table_name}, primary_key: false)` with `add :id, :binary_id, primary_key: true`, TODO field comments, and `timestamps(type: :utc_datetime_usec)`.
- Return `{String.trim(source), file_path}`.

**gen_queries/2** `(module_name, schema_module)`:
- Generate a module with `import Ecto.Query`, `alias #{schema_module}`.
- `list/2` function: takes `(repo, opts \\ [])`, extracts `:page` (default 1) and `:page_size` (default 20), computes offset, calls `repo.all(from(q in #{schema_module |> String.split(".") |> List.last()}, limit: ^page_size, offset: ^offset))`.
- `get_by/2` function: takes `(repo, filters)` where filters is a keyword list, calls `repo.all(from(q in #{schema_module |> String.split(".") |> List.last()}, where: ^filters))`.
- Include `@moduledoc` and `@doc` annotations.
- Return `{String.trim(source), Naming.module_to_file_path(module_name)}`.

```elixir
  name = field["name"]

end
```
