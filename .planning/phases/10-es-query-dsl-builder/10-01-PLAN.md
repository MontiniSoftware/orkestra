| T-10-01 | Tampering | Query.must/2 clause values | accept | DSL is pure data builder; clause values are opaque maps forwarded to ES. Sanitization is caller's responsibility. | T-10-02 | Information Disclosure | Query structure | accept | Query maps contain no secrets; they describe search criteria. The DSL produces maps consumed within the same BEAM node -- no cross-trust-boundary serialization occurs in the DSL itself. |
