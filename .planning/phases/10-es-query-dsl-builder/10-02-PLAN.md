    ```
      @moduledoc "Generate an ES Queries module with search/3, list/3, and get_by_id/3 helpers for an ES projection"

      schema do
        field(:module_name, :string,
          required: true,

        field(:projector_module, :string,
          required: true,
          description: "The ES projector module, e.g. MyApp.Orders.OrderESProjector"
        )
      end

      @impl true
      def execute(%{module_name: module_name, projector_module: projector_module}, _frame) do
        project_dir = Application.get_env(:orkestra_mcp, :project_dir)
        {source, file_path} = OrkestraMcp.Generator.gen_es_queries(module_name, projector_module)
        written = OrkestraMcp.Generator.write!(source, project_dir, file_path)
        {:ok, "Created #{written}\n\n```elixir\n#{source}\n```"}
      end
    end
    ```

| T-10-03 | Tampering | gen_es_queries module_name input | mitigate | module_name is interpolated into generated source. Naming.module_to_file_path constrains file path to lib/ subdirectory. | T-10-04 | Tampering | Generator.write! path traversal | accept | write! uses Path.join(project_dir, file_path) where file_path comes from module_to_file_path which always produces "lib/..." paths. Existing pattern shared by all generators; no new risk introduced. |
| T-10-05 | Information Disclosure | Generated source contains module names | accept | Module names are project-internal identifiers with no sensitive data. Generated files are written locally by the developer. |
