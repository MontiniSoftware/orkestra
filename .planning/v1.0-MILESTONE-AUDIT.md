## Integration Findings (Fixed)

Two integration blockers were found and fixed:

1. **Slug algorithm divergence** — MCP generator used `Macro.underscore` per-segment, DSL used `String.downcase() |> String.replace(".", "_")`. Fixed by aligning DSL to `Macro.underscore` pattern.

2. **Default event_store** — Both DSL and MCP generator defaulted to `Orkestra.EventStore` (behaviour module with no concrete functions). Fixed to `Orkestra.EventStore.InMemory`.
